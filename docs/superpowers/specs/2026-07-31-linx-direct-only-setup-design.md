# LinX 添加流程固定直连设计

## 目标

选择 `MicroTech LinX` 后，添加页面不再显示 `直接连接 / 广播数据` 选项。用户点击搜索按钮后，Loop 直接搜索并连接 LinX 设备。

## 当前决定

- 新添加的 LinX 固定使用直接连接。
- 不迁移已经保存的广播配置；该版本尚未发布，无需兼容真实用户数据。
- 底层广播解析、日志和测试暂时保留，但不提供用户入口。
- 过去的广播设计和实施记录保留为历史，不再代表当前添加流程。

## 页面

添加页面保留现有说明和搜索按钮，删除连接方式选择控件，也不显示“直接连接”或“广播数据”模式文字。

## 连接行为

点击搜索按钮时，添加流程显式把当前连接方式设为直接连接，再开始扫描。这样即使测试或临时状态中存在广播值，本次添加仍只会走直连流程。

## 验证标准

1. 添加页面不显示连接方式选择控件和“广播数据”按钮。
2. 连接方式区域不再显示“直接连接”或“广播数据”，搜索按钮仍然可见并可点击；页面原有说明和取消操作保持不变。
3. 添加流程开始扫描前，连接方式已固定为直接连接。
4. MicroTech 单元测试全部通过。
5. 更新并实际运行 `LoopUITests` 真机添加流程测试，确认连接方式选择控件、“直接连接”和“广播数据”均不存在，搜索按钮存在。
6. 完整 App 使用 `LoopWorkspace` 构建，包内仍包含 MicroTech、Nightscout 插件。
7. `README.md`、`PROGRESS.md` 当前状态和相关排障说明改为“新添加仅直连”；旧设计及旧进展保留并标明为历史记录。

## 发布

旧 TestFlight 构建已在上传前取消。完成代码、测试、完整插件检查和真机验证后，重新触发 TestFlight 发布，并等待 App Store Connect 处理完成。
